# XC2263N 聚合实验结果

当前标签目标为静态检测报告诊断，不能将其直接解释为真实生产漏洞。346 个函数：263 报告正例、47 报告负例、36 未知。已知 310 个划为训练 225（190/35）、验证 54（48/6）、测试 31（25/6）。源文件有重叠，测试结果已在开发中被查看。

两轮共 45 个新增运行，复用同一组 3 个 Full 基线，共 48 个不同配置/seed。三个 seed 共用初始权重，改变训练随机过程；不是三个独立数据集。阈值由验证集选择。

## 如何解释

- Full 的平均正类 F1 约 0.9335，但测试中全正预测的 F1 已为 0.8929。负例只有 6 个，须联合看负类召回、Macro-F1、排序和 CE。
- 去调用边未改变本轮三个 seed 的分类结果，排序表现下降；还不能认定模型已经依赖调用关系发现真实跨函数漏洞。
- 参数绑定在验证和测试中没有直接覆盖，本轮不能检验它的泛化贡献。
- 去 guard 或 REF 后阈值分类与排序变化方向不一致，不能只按一个指标宣布每个模块有效。
- 输入只有一个有效段，不能以这些实验证明多段聚合收益。容量干预不完全匹配，相关限制继续保留。
- 返回关系与历史 guard 的新增神经分支只完成表示、兼容性和梯度检查，未完成本轮学习有效性验证。

## 历史结果

SARD Task27 开发验证：seed123 的 TP/TN/FP/FN=135/19/0/0，F1=1.0000；seed2024 为134/19/0/1，F1=0.9963。它按验证最佳 epoch 选择，不是独立测试。对应 BigVul 开发验证 F1 为 0.2222 和 0.1200。

较早 V2/V3 机制实验：训练 F1 从 0.8235 升至 0.8750，CE 从 0.4317 降至 0.3260；冻结机制验证 F1 从 0.3636 降至 0.2500，CE 从 0.7464 升至 0.8398。排序指标上升不等于固定阈值检出更好。

MISRA 注释代理 F1：V2/V3=0.6154/0.6034；ISO17961 注释代理为0.6383/0.5532。使用当时的200步模型，不能与当前800步结果混用，也不等于生产漏洞真值评估。

详细聚合值见 [结果目录](../results)。逐函数预测、源码标签定位、机器及环境元数据未公开，本地原始证据保持不变。

## 主要结果

当前 XC2263N 报告目标包含 263 正、47 负、36 未知。使用 310 个已知标签，训练/验证/测试为 225/54/31 个函数，正负分别为 190/35、48/6、25/6。分组划分存在源文件重叠，且测试结果已经在开发中查看，不能写成项目外盲测。

| 配置（三 seed 测试均值） | 正类 F1 | Macro-F1 | ROC-AUC | AP | CE |
|---|---:|---:|---:|---:|---:|
| Full V2 | 0.9335 | 0.8232 | 0.9067 | 0.9747 | 0.3520 |
| 去调用边 | 0.9335 | 0.8232 | 0.8667 | 0.9412 | 0.3696 |
| 去参数绑定 | 0.9335 | 0.8232 | 0.9044 | 0.9741 | 0.3503 |
| 去 guard 输入 | 0.9191 | 0.7977 | 0.9111 | 0.9766 | 0.3508 |
| 去 REF 输入 | 0.9188 | 0.7975 | 0.9267 | 0.9808 | 0.3518 |

阈值通过验证集选择。45 个新增消融运行复用同一组 3 个 Full 基线，总计 **48 个不同配置/seed、16 组配置**。三个 seed 共用初始权重；不能视为三个独立数据集。

历史 SARD Task27 开发验证 F1 为 1.0000/0.9963，按最佳验证 epoch 选择；同任务 BigVul 为 0.2222/0.1200。较早 V2/V3 机制实验的训练拟合改善与验证退步同时存在。相关聚合结果均保留，详见[实验报告](docs/EXPERIMENT_RESULTS.md)。
